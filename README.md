# java-lotto-precourse

# 프로젝트 개요
사용자가 입력한 구입 금액, 당첨 번호, 보너스 번호를 기반으로 로또 발매 및 당첨 결과를 계산한다.
로또는 중복되지 않은 6개의 숫자로 구성되며 사용자가 구매한 로또와 당첨 번호를 비교해 등수 및 수익률을 출력한다.

# 구현 기능 목록
### Domain
1. Lotto
- 로또 한 장(6개 번호)를 표현하는 객체
- 로또 번호 저장, 정렬, 유효성 검증(6개, 중복 없음, 1~45 범위)

2. LottoRank 
- 등수(출력값 아님), 일치 조건, 상금을 관리하는 Enum

3. WinningLotto
- 당첨 번호화 보너스 번호를 관리하는 객체
- 보너스 번호 중복 검증
- 일치 개수 계산

4. LottoResult
- 전체 구매 로또들의 결과를 집계하는 클래스
- 등수별 당첨 개수 저장
- 전체 상금 합계 계산
- 수익률 계산

### Service
1. LottoService
- 로또 발행 및 당첨 결과 계산 핵심 로직
- 구입 금액 기반 로또 n장 발행
- 랜덤 변호 생성
- 사용자가 구매한 로또와 당첨 번호 비교 후 결과 반환

2. LottoGenerator
- 랜덤 로또 생성 담당

### View
1. InputVieW
- 사용자 입력 처라
- 구입 금액, 당첨 번호, 보너스 번호

2. Outputview
- 실행 결과 출력 담당
- 구매한 로또 목록, 당첨 결과 및 수익률 출력

### Controller
1. LottoController
- 프로그램 전체 실행 흐름 담당
